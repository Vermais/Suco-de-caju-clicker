# Suco de Caju Clicker

Jogo incremental para navegador. Clique no copo para produzir suco de caju, compre máquinas e melhorias e acumule produção automática. O progresso é salvo no navegador.

## Executar

Abra `dist/index.html` no navegador. Para publicar na Vercel, importe este repositório; a configuração em `vercel.json` serve a pasta `dist`.

O jogo está preparado para uma futura integração com o [álbum do Pedro Victor](https://album-pedro-victor.vercel.app/#album).
